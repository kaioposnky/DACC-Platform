# DACC Platform

Bem-vindo ao repositório unificado da Plataforma Digital Acadêmica do DACC (Diretório Acadêmico de Ciência da Computação).

Este monorepo agrupa tanto o back-end quanto o front-end da solução.

## 📂 Estrutura do Projeto

| Módulo | Tecnologia | Descrição | Documentação |
| :--- | :--- | :--- | :--- |
| **API** | .NET 7 / C# | API REST completa com gestão acadêmica e e-commerce. | [Acessar Documentação](./webapi/README.md) |
| **Website** | Next.js / React | Interface frontend utilizando Atomic Design. | [Acessar Documentação](./website/README.md) |

## 🚀 Como Rodar

Para instruções específicas de instalação e execução, por favor acesse o `README` dentro da pasta de cada projeto nos links acima.
